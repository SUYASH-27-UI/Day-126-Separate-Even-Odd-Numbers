# Python Day 126 - Separate Even and Odd Numbers

This Python program separates even and odd numbers from a list into two different lists.

## Example

Original list:
```text
[10, 15, 20, 25, 30, 35]
```

Output:
```text
Even numbers: [10, 20, 30]
Odd numbers: [15, 25, 35]
```

## Concepts Used

- Python lists
- `for` loop
- `if-else` statements
- Modulus `%` operator
- `append()` method

## How It Works

The program checks each number in the original list. If a number is divisible by 2, it is added to the even list. Otherwise, it is added to the odd list.

## What I Learned

I learned how to separate even and odd numbers into different lists using a loop and conditional statements.
